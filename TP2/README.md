## Resumo
Implementar um conversor de elementos básicos de Markdown para HTML em Python, com recurso a Expressões Regulares (módulo `re`). O processador identifica e converte linha a linha cabeçalhos e blocos de listas numeradas, aplicando filtros de substituição para elementos *inline* (imagens, hiperligações, texto a negrito e texto em itálico).
